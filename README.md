One funny line for make.fun's "The One-Line Laugh" bounty (round 3, final): a spam filter so good it locks out its own owner. The program writes the line to `/output/entry.txt`, checking first that it is exactly one sentence of 1–200 characters.

> My spam filter is so good it caught my own email to myself, so now even I can't reach me.

## Run it

```sh
node main.ts
```

It writes `/output/entry.txt` (89 characters, no trailing newline), reads it back, and prints its length and sha256.
